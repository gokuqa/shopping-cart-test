# 🚀 Cómo instalar y ejecutar el proyecto

Sigue estos pasos para configurar y ejecutar el proyecto en tu entorno local.

### 1️⃣ Clonar el repositorio

Abre una terminal y ejecuta:

```bash
git clone https://github.com/gokuqa/shopping-cart-test.git
cd shopping-cart-test
2️⃣ Cambiar a la rama de desarrollo
Si aún no estás en la rama develop, ejecuta:


git checkout develop
3️⃣ Instalar dependencias
Para instalar todas las dependencias necesarias, ejecuta:


npm install
4️⃣ Iniciar el servidor en modo desarrollo
Ejecuta:

npm run dev
El proyecto estará disponible en:

🔗 http://localhost:3000/
